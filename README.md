## Standard Roll Label Unwind Chart (#1–#4 Primary Orientations)

| Unwind Code | Orientation off the Roll | Common Application |
|---|---|---|
| **Unwind #1** | Top of label comes off first | Machine applicators wrapping from top-leading edge |
| **Unwind #2** | Bottom of label comes off first | Bottom-leading rotary and flatbed labelers |
| **Unwind #3** | Right side of label comes off first | Most vertical bottle & jar wrap-around applicators |
| **Unwind #4** | Left side of label comes off first | Reverse-feed rotary wrap-around applicators |
